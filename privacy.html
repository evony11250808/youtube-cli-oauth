Privacy Policy for YouTube CLI Local

Effective date: September 23, 2026

YouTube CLI Local is a personal desktop command-line tool operated solely by its owner to manage the owner's own YouTube channel. It is not offered as a public service.

Google user data accessed

The application uses Google OAuth 2.0 and the YouTube Data API v3. With the owner's authorization, it may access the owner's basic Google account identity and YouTube channel data, including video metadata, titles, descriptions, tags, localizations, and captions.

How data is used

Data is used only to display, update, localize, or upload metadata and captions for videos selected by the owner. It is not used for advertising, profiling, or any unrelated purpose.

Storage and security

OAuth credentials and access or refresh tokens are stored locally on the owner's computer. This website does not collect, receive, or store Google user data.

Sharing and disclosure

Google user data is not sold, rented, or shared with third parties. Data is transmitted only between the local application and Google APIs as necessary to perform actions requested by the owner.

Retention and deletion

Locally stored OAuth tokens remain until the owner deletes them or revokes access through the Google Account permissions page. The owner may delete local tokens at any time.

Limited Use

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions may be submitted through the repository's GitHub Issues.
